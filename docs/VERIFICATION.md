## Демонстрация проекта

1. Войти и показать главную: статистику, последние записи, разделы анализов и исследований.
2. Открыть **Категории → Создать свою категорию**. Создать «Витамины» с показателями «Витамин D» и «Магний», единицами и интервалами.
3. Сохранить несколько записей за разные даты, добавить числовые результаты и PDF/изображение.
4. Открыть историю категории: сравнить значения, показать отдельные записи за один день и цветовые статусы.
5. Перейти в **Аналитика и графики**: выбрать показатель, ограничить даты, показать график, минимум/максимум/среднее/изменение, выгрузить CSV и PDF.
6. Через **Аккаунт → Персональные нормы** задать свой интервал и показать обновление статусов. Вернуть общий интервал кнопкой сброса.
7. Отредактировать запись, скачать вложение, показать подтверждение удаления.
8. Показать редактирование своей категории и защиту показателя с сохраненными результатами от удаления.

Не используйте тестовый хост для хранения настоящей медицинской истории: это отдельный воспроизводимый сценарий проверки. Для работы предназначен обычный запуск проекта из Visual Studio или `dotnet run --project HealthCard.Web`.
